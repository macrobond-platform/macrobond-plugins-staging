# Macrobond

The Macrobond MCP server searches and retrieves economic and financial time series. This skill's guidance comes in two versions, one for each kind of host. Check your tool list, then read the matching file in this skill's folder and follow it:

- If your host does not show widgets (`render_series_picker` is not in your tool list), read `no-widgets.md`.
- Otherwise, read `widgets.md`.

Read only that one file; the other is written for tools you do not have.
